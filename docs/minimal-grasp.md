# 最小夹持物理验证

此实验独立于容器流程。入口为 `examples/minimal_grasp_physics.py`，结果位于
`artifacts/minimal_grasp/`。只验证一个 60 mm、80 g 方块在平行夹爪中的夹持、运输和释放。

## 运动与接触模型

现有适配器中的两个独立 mocap 夹指是运动学刚体，直接更新 `mocap_pos`。
它们没有可积分的运动自由度；几何位置进入碰撞检测，但直接移动 mocap
不会产生与真实动力学关节等价的惯性和广义速度。声明 geom 的质量不能使其成为动态夹指。

本实验选用共同动态基座加左右开合关节：

- 基座有 freejoint 和质量；唯一 weld 连接 mocap 控制目标与动态基座。
- 两指是基座的子刚体，各重 40 g，各有一个 slide 关节，由位置执行器驱动。
  刚度 800 N/m、速度增益 8 N·s/m，每侧执行器限力 ±5 N。
- 控制目标沿五次平滑轨迹移动。基座约束力驱动动态基座，两侧执行器驱动关节；
  MuJoCo 积分得到实际 `qpos/qvel`，接触雅可比将这些速度映射到接触点。
  接触求解器根据法向约束及库仑摩擦计算接触力，再反馈到方块和夹爪的动力学。
- 方块只有 freejoint。运行中不写方块状态，不使用方块 weld、吸附或外加支撑力。
  垂直承重来自侧面切向摩擦。夹指底部初始比方块底部高 8 mm，掌部留有间隙。

滑动摩擦系数为 0.8，接触维数为 3（不依赖扭转或滚动摩擦）。闭合目标每侧
18 mm，实际受物体阻挡约 15 mm；每侧法向力约 2.4 N。

## 实验与判定

| 阶段 | 时间（秒） | 动作 |
|---|---:|---|
| 静置 | 0–0.6 | 方块在桌面静止 |
| 闭合与保持 | 0.6–2.1 | 两指侧向闭合，保持 0.5 秒 |
| 抬升 | 2.1–3.6 | 抬升 8 cm |
| 悬停 | 3.6–4.2 | 保持 0.6 秒 |
| 水平运输 | 4.2–6.0 | 沿 x 移动 12 cm |
| 悬停 | 6.0–6.6 | 保持 0.6 秒 |
| 张开 | 6.6–7.4 | 张开夹爪，方块自由下落 |
| 稳定 | 7.4–8.4 | 观察落桌后稳定 |

`continuous.mp4` 为同一仿真连续输出的 50 fps 视频，无剪辑、无阶段重置。
`trace.csv` 每 0.5 ms 一行，共 16800 行，包含方块高度、实际基座位置、
基座坐标系下方块相对位置、两侧接触力与有效接触、执行器力、关节位置、
穿透深度和支撑检查量。`trace.png` 为完整时间曲线，`result.json` 为机器判定。

有效接触要求该侧合计法向力超过 0.05 N，且承载接触法向与夹指侧向夹角余弦
大于 0.95。悬停和运输的每个采样都要求双侧有效接触、方块高于初始至少 5 cm、
相对位置漂移小于 2 mm、无桌面或掌部支撑。还检查侧面法向垂直分力小于
0.01 N、夹指底部高于方块底部至少 5 mm，避免把指尖托举当成摩擦夹持。
闭合阶段不允许高度跳升超过 2 mm；全程最大穿透必须小于 1 mm。
释放要求双侧接触消失、存在无桌面支撑的向下运动，测得加速度接近重力，
随后回到桌面并持续稳定。通过不依赖单帧高度。

## 本次结果与限制

最小实验通过：最小持续抬升约 79.99 mm，水平运输约 120.00 mm；两次停留
各 0.6 秒。运输阶段相对位置最大漂移约 0.00030 mm，最小每侧法向力约
2.3985 N。最大穿透约 0.573 mm，发生在落桌冲击；自由落体加速度约
−9.81 m/s²。零摩擦反证无法抬升或运输方块，见 `artifacts/minimal_grasp_zero_friction/`。
反证使用 `condim=1` 纯法向接触，移除切向摩擦维度；方块全程稳定留在桌面。
直接将三维摩擦接触系数设为零在当前求解设置下出现数值异常，因此不作为有效反证。

第一轮使用 1 ms 时间步、6 ms 接触时间常数和默认摩擦求解，虽能运输，但发生
约 2 mm 缓慢滑移、落桌穿透约 2.3 mm，未通过严格检查。最终改为 0.5 ms
时间步、2 ms 接触时间常数，启用 MuJoCo 的 10 次 `noslip_iterations`
后处理以抑制软接触慢滑移；摩擦系数、夹紧目标和力上限均未增加。
这些是数值求解设置，不代表真实材料具有同等精度；极小漂移不能外推为实物精度。

本轮未接回容器。后续可采用这一动态结构作为候选驱动方案，但仍需分别验证
运输不丢失、张开后释放、夹爪撤离、物体完全进入容器并稳定落定；
不能仅以双侧接触或抬升作为最终任务成功。

## 复现

```bash
python3 -m pip install -e '.[simulation]' matplotlib
MUJOCO_GL=egl python3 examples/minimal_grasp_physics.py --plot
python3 -m pytest tests/test_minimal_grasp_physics.py -q
```

视频生成需要 PATH 中可用的 `ffmpeg`；仅运行物理检查可加 `--no-video`。
本次使用 MuJoCo 3.13.0。`model.xml` 保存实际仿真模型。
